# Türkçe Eğitsel Oyunlar 🎮📚

Bu depo, Türkçe derslerini öğrenciler için daha interaktif, heyecanlı ve kalıcı kılmak amacıyla geliştirilmiş web tabanlı eğitsel oyunları içerir.

## 🗂️ Kategoriler ve Oyunlar

### 📖 Masal / Metin Türleri
- **Masal Eşleştirme Oyunu (`Masal 1 eşleştirme.html`):** Masalın yapı unsurlarını ve kavramlarını eşleştirme.
- **Üç Haylaz'ın Yolu (`Üç Haylaz Masalı oyunu.html`):** Macera haritasında soruları çözerek çiftliğe ulaşma.

### ⚙️ Fiilde Çatı
- **Etken / Edilgen Yarışması (`Etken edilgen.html`):** Cümlelerdeki özne-yüklem ilişkisini belirleme.
- **Geçişli / Geçişsiz Fiil Yarışması (`Geçişli geçişsiz.html`):** Nesne-yüklem ilişkisini kavrama.
- **Köstebek Vurmaca (`geçişsiz fiil köstebek.html`):** Geçişsiz fiilleri reflekslerle yakalama.

### ✍️ Anlatım Bozuklukları
- **Kelime Ormanı (`3anlatım bozukluğu ormanı oyun.html`):** Doğru cevaplarla ağaç dikip orman kurma.
- **Kelime Hazinesi (`Anlatım bozukluğu sandık oyun.html`):** Hazine ve ganimet toplama yarışması.
- **Mega Çarkıfelek Pro (`çark anlatım bozukluğu 5.html`):** Çark çevirerek puan ve pas hamleleri.
- **Mega Çarkıfelek Özel İsimli (`çark anlatım bozukluğu 6.html`):** Grup isimleriyle çarkıfelek müsabakası.
- **Zarf Avı (`ZARF AÇ anlatım bozukluğu oyun.html`):** Gizemli zarflardan çıkan sorularla sürpriz puan avı.

## 🚀 Canlı Önizleme
Depoyu GitHub Pages üzerinden yayınlamak için:
1. `Settings` > `Pages` sekmesine gidin.
2. `Branch: main` seçip kaydedin.
3. Portalınız doğrudan `https://pinar681.github.io/Turkce-Egitsel-Oyunlar/` adresinde yayında olacaktır!
